Project Visual Orientation

How to read this repository without mistaking artifact completeness for domain validity.

Reading Route

  1. Start with the claim boundary.
  2. Read the manuscript as a reflexive case study, not as a technical battery or cosmology result.
  3. Use the evidence map to understand how the two internal cases are used.
  4. Check the manifest for package integrity.

Not a Domain Claim

  • No practical battery technology.
  • No BMS method or safe-charging protocol.
  • No Hubble-tension solution.
  • No Lambda-CDM replacement.
  • No likelihood, MCMC posterior, or evidence comparison.

What It Preserves

The repository preserves a first-person, AI-assisted record of how research-like artifacts can grow rapidly and then be reduced by grounding checks and public claim-boundary discipline.
