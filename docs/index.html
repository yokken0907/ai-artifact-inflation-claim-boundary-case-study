Artifact Inflation Without Epistemic Grounding

A claim-bounded, AI-assisted reflexive case study of artifact inflation, epistemic grounding failure, and claim-boundary control in non-expert AI-assisted research.

非専門家によるAI支援研究における成果物膨張と主張境界管理の自己事例型ケーススタディ。

Claim Boundary

  • This project is not a battery-technology paper.
  • This project is not a cosmological result.
  • This project does not claim that AI-assisted research is useless.
  • This project does not evaluate expert-led AI-assisted science.
  • This project is a reflexive case study of artifact inflation and claim-boundary control.

Central Thesis

Generative AI can rapidly create complete-looking research artifacts, but artifact completeness does not by itself establish domain validity.
