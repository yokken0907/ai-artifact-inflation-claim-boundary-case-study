# Artifact Inflation Without Epistemic Grounding

**Version:** v0.1.3-public-landing-and-metadata-refresh  
**Date:** 2026-06-04  
**Author:** Keiji Yoshimura  
**Project website:** https://yokken0907.github.io/ai-artifact-inflation-claim-boundary-case-study/  
**Repository:** https://github.com/yokken0907/ai-artifact-inflation-claim-boundary-case-study

本リポジトリは、非専門家によるAI支援研究において、論文・コード・図表・リポジトリ・投稿メタデータなどの「研究らしい成果物」が急速に膨らみうる一方、それが専門領域における妥当性を保証しない、という失敗境界を記録した自己事例型ケーススタディです。

## 位置づけ

これは、バッテリー技術論文でも宇宙論の成果でもありません。  
また、AI支援研究一般が無効であることを示す統計的研究でもありません。

本資料は、著者自身のAI支援プロジェクトのうち、以下2件を素材にした主張境界・失敗境界の記録です。

1. リチウムイオン電池モデル監査：技術提案ではなく、簡略モデルと外部放電データに関する残差監査・専門家確認前資料へ縮退した事例。
2. A10派生ハッブルテンション足場監査：物理的な E(z)/H(z) 接続、実データlikelihood、MCMC posterior、evidence比較へ到達せず、失敗境界記録へ縮退した事例。

## 明示的に主張しないこと

本リポジトリは、以下を主張しません。

- 実用的なバッテリー技術
- BMS手法
- 安全充電法
- 劣化低減、リチウム析出回避、EV/自動車安全性
- ハッブルテンションの解決
- Lambda-CDMの置換
- 検証済み宇宙論モデル
- 実データlikelihood、MCMC posterior、Bayesian evidence比較
- AI支援研究すべてに関する統計的結論
- 専門家主導のAI科学への評価または否定

推奨される公開時の説明は次です。

> これは、非専門家によるAI支援研究における成果物膨張と主張境界管理に関する、AI支援の自己事例型ケーススタディです。バッテリー技術論文でも宇宙論成果でもありません。
