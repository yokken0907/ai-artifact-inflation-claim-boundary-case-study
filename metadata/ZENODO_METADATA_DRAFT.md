## Description

Artifact Inflation Without Epistemic Grounding v0.1.3 is a claim-bounded public repository refresh of a reflexive case study on artifact inflation, epistemic grounding failure, and claim-boundary control in non-expert AI-assisted research.

The preserved manuscript examines two author-supplied AI-assisted project histories: a lithium-ion battery-model audit and an A10-derived Hubble-tension scaffold audit. In both cases, generative AI helped produce research-like artifacts, but strict grounding checks reduced the projects to claim-boundary or failure-boundary records rather than validated technical or scientific results.

The central claim is methodological and bounded: artifact completeness does not by itself establish domain validity. Non-expert AI-assisted research therefore requires explicit domain-grounding, prior-art, external-data, implementation-or-experiment, expert-review-worthiness, and public-claim-boundary gates before public scientific or technical claims are made.

This v0.1.3 release does not introduce new case claims beyond the archived v0.1.2 ai.vixra-oriented manuscript. Its purpose is to refresh the public repository structure, strengthen claim-boundary orientation, add GitHub Pages landing materials, provide metadata drafts, and regenerate file manifests.

This release does not claim a practical battery technology, BMS method, safe-charging protocol, degradation-reduction result, lithium-plating avoidance result, Hubble-tension solution, Lambda-CDM replacement, validated cosmological model, observational likelihood, MCMC posterior, Bayesian evidence comparison, or statistical conclusion about all AI-assisted research. It also does not evaluate or discredit expert-led AI-assisted science.
